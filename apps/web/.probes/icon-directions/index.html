Icon directions · Κατευθύνσεις εικονιδίων

Six platform glyphs drawn three ways, at 24px (navigation/list size) and 16px (meta size), on light and dark. A is today's Lucide baseline. B "Bay duo" keeps the same line weight but adds one lilac element per icon — the mark's colour appears exactly once, so the set is unmistakably ours without being loud. C "Link" builds every glyph from two strokes that cross or meet — the platform's idea (two founders linking) carried into the icon system itself.

How to read it. A is what every SaaS ships — safe, immediately readable, zero identity. B keeps A's anatomy and marks one element per icon in the brand lilac — recognisable as CoFounderBay while staying calm enough for the rail and the sidebar. C is the most ownable: every glyph is two strokes that cross or meet (the platform is literally "two founders link"), but it is the biggest departure and needs a full icon family drawn, not just these six. My recommendation: adopt B for chrome icons now (drop-in, same grid), and let C grow only for the six brand surfaces (nav modes, landing, empty states) if you like the direction.
